# WinRAR No Ads

Simple patch to remove the annoying purchase popup from WinRAR.

## What it does

Removes this popup that shows every time you open WinRAR:
![image](https://github.com/user-attachments/assets/b395a756-0dae-41f0-8163-9b6e5c183a47)

## How to use

1. Compile the code
2. Run it as admin
3. Done

## Installation

The program will replace your existing WinRAR.exe with the patched version.
